# sims

과학 수업 사이트. GitHub Pages로 공개한다. 학생은 첫 화면에서 과목 › 단원 › 차시 순서로 들어간다.

| 경로 | 내용 |
|---|---|
| `index.html` | 수업 홈 (과목 목록) |
| `ts2/` | 통합과학2 차시 목록 |
| `ts2/earth/01/` | 지구 환경의 변화 1차시 (수업 화면 · 학습지 · 개념 노트 · 스스로 풀기) |
| `elnino/` | 시뮬레이션: 무역풍과 적도 태평양 |
| `assets/` | 차시 페이지 공통 모양(`lesson.css`)과 동작(`lesson.js`) |

## 차시 페이지 주소 뒤에 붙이는 값

`?p=a` 기본 · `?p=b` 문장 틀 학습지 · `?p=c` 기기 없음 · `?p=d` 시간 부족 · `?p=e` 모둠·심화.
값을 붙이지 않으면 기본이다. 페이지 아래쪽 `presets`에서 장면 자리별 안을 고른다.

## 제출 받기

차시 페이지 아래쪽 `formUrl: ''` 따옴표 안에 구글 설문 주소를 넣으면 「제출하기」 버튼이 나타난다.

학생 답과 기록은 이 저장소에 두지 않는다. 학습지에 쓴 답은 학생 기기에만 남고, 제출은 구글 설문으로 받는다.
