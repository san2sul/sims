# 무역풍과 적도 태평양 (엘니뇨 시뮬레이션)

- 과목·단원: 통합과학2 Ⅱ-1 생태계와 환경 › 지구 환경의 변화
- 성취기준 (2022 개정): [10통과2-02-03] 온실효과 강화로 인한 지구온난화의 메커니즘을 이해하고, 엘니뇨, 사막화 등과 같은 현상이 지구 환경과 인간 생활에 미치는 영향과 대처 방안을 분석할 수 있다.
- 수업: 1차시 「시뮬레이션 학습 + 예측·관찰·설명 → CER」 (CER 도입 차시)

## 사용법

1. 무역풍 세기(0~100)를 정한다. 50이 평상시다.
2. 「시간 흐르게 하기」를 누른다. 1초가 약 2개월이다.
3. 6개월 이상 지나면 「기록하기」를 누른다.
4. 바람 세기를 바꿔 3~4번 기록한 뒤 「표 복사하기」로 활동지나 AI 피드백 프롬프트에 붙인다.

## 보여 주는 값

서쪽·동쪽 표층 수온, 동쪽 수온 약층 깊이, 동쪽 용승 세기(상대값), 비구름이 많은 곳.

## 모형의 한계

교육용 단순 모형이다. 수치는 실제 관측의 대략적인 범위를 흉내 낸 값이고(평상시 동쪽 약 25 ℃, 서쪽 약 29 ℃), 대기 순환과 지구 자전 효과는 단순화했다. 학생에게 "관측값이 아니라 모형 값"임을 알려 준다.
